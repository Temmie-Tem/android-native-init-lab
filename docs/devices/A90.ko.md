# Samsung Galaxy A90 5G

[English](A90.md) · **한국어**

## 기기 / SoC / kernel

- 기기: Samsung Galaxy A90 5G (`SM-A908N`, board codename `r3q`).
- SoC: Qualcomm SM8150 / Snapdragon 855 (`msmnile`).
- Kernel: Samsung vendor Linux 4.14.190. 확립된 native-init 결과의 대부분은
  custom ramdisk와 stock kernel을 사용했습니다. Self-built-kernel track은 더
  최근에 시작됐으며 여전히 범위가 제한된 프론티어입니다.

## 역할

A90은 이 프로젝트에서 가장 성숙한 native-runtime 및 Debian-server 연구
대상입니다. Native PID 1은 vendor-kernel hardware를 bring-up하고 recovery
supervisor로 남습니다. 선택된 product architecture는 Wi-Fi를 native 소유로
유지하며, 하나의 isolated child에 별도 PID, mount, IPC, UTS, network namespace를
제공한 뒤 해당 child를 Debian PID 1로 만듭니다.

## 증명된 capability

- **PROVED(증명됨) — native PID 1과 resident recovery model.** Static custom
  `/init`가 PID 1로 boot했고, bounded resident command/runtime surface를
  제공했으며, 서로 분리해 journal한 여러 run에서 known resident health로
  복귀했습니다.
- **PROVED(증명됨) — USB ACM과 NCM.** Native boot에서 A90 ACM identity와
  composite NCM 경로가 나타났습니다. Bounded health run은 serial control,
  direct NCM, host/device IP reachability, TCP control path를 증명했습니다. ACM
  numbering은 epoch 사이에 안정적이라고 간주하지 않습니다.
- **PROVED(증명됨) — native Wi-Fi.** 서로 분리된 bounded experiment에서
  internal ICNSS/qcacld WLAN 경로가 association, DHCP, IP traffic까지
  도달했습니다. 이후 증거는 선택된 Debian architecture에서 native Wi-Fi
  ownership이 구조적 요구사항임을 보였습니다.
- **PROVED(증명됨) — native audio.** Bounded live run에서 SM8150 audio card를
  materialize하고, 필요한 calibration과 route를 replay하고, internal speaker로
  PCM write/drain을 수행한 뒤 route를 cleanup하고 exact rollback path로
  복귀했습니다.
- **PROVED(증명됨) — bounded Debian handoff run.** 개별 journaled run에서
  Debian `sysvinit` PID 1, key-only Dropbear SSH, native DRM release, Debian DRM
  master/`SETCRTC`, automatic native return, cleanup, final resident health를
  증명했습니다. 이는 run-specific result이며 standing authority가 아닙니다.

## 부분 증명 / 관측

- **observed(관측됨) — Debian networking, SSH, Wi-Fi, display는 실제 live
  capability로 존재합니다.** 그러나 가장 강한 증거는 서로 다른 bounded
  experiment에 분산돼 있습니다. 저장소는 이를 합쳐 새로운 persistent-server
  PASS를 만드는 것을 명시적으로 금지합니다.
- **PROVED(증명됨), 단 mechanical boundary에 한정 — direct UFS handoff.** H16은
  과거의 multi-gigabyte SD work copy 없이 read-only UFS appliance에서
  `switch_root`에 도달했습니다. 그 run은 authenticated SSH, final Wi-Fi,
  Debian PID 1, display, full persistent-server readiness를 증명하지 않았습니다.
- **designed(설계됨) — isolated Debian successor.** Namespace, minimal `/dev`,
  resource control, key handling, evidence, cleanup, native-Wi-Fi boundary가
  상세히 명세되고 host review를 받았습니다. 전체 architecture는 하나의 live
  terminal run에서 구현·증명되지 않았습니다.
- **observed(관측됨) — H34 boot-loop correlation.** Host analysis는 H34가
  `rtic_mp`를 누락하면서 stale stock RTIC DTB를 유지한 artifact inconsistency를
  증명했습니다. 이는 강한 causal candidate이지만 exact device-side RTIC/QHEE
  causality는 unproved(미증명)입니다.

## 아직 증명되지 않은 것

- Debian PID 1, authenticated SSH, final native-owned Wi-Fi, 선택된 no-PTY
  four-node `/dev`, namespace isolation, bounded resource behavior, recovery,
  final health를 모두 닫는 하나의 persistent isolated-Debian run.
- Public-MPGen self-built kernel의 반복 가능한 정상 운영 또는 functional
  equivalence. Transfer/readback, System return, operator demo 관측만으로는
  그 결과를 증명하지 않습니다.
- Public MPGen producer와 Samsung stock producer의 exact equivalence, 또는
  proprietary RTIC/QHEE component가 measurement metadata를 받아들인다는 것.
- H41 playback과 완료된 rollback/health 종결. 이전 playback 관측과 정상 V2321
  복귀 기록이 H41을 종결하지는 않습니다.

## 현재 프론티어

2026-09-05 확인 기준으로 `GOAL_A90.md`의 선택 작업은 H41 rollback recovery입니다.
H41 run-02는 candidate write/readback과 System return을 확인했지만, 수동 Bad Apple
action은 `RC=-110`으로 timeout됐습니다. Playback은 **unproved(미증명)**입니다.
원래 rollback은 두 Samsung 기기가 inventory에 있어 helper dispatch 전에
멈췄으며 rollback write는 0회였습니다. 복구 종결은 GOAL과 target contract에 기록된
exact continuation을 따릅니다. 이전의 healthy V2321 복귀는 과거 reference이며
H41 복구 완료의 증거가 아닙니다.

Self-built-kernel track은 exact compiler, deterministic public-MPGen output,
일치하는 RTIC metadata라는 **PROVED(증명됨) host-side structural consistency**를
보존합니다. H35의 pre-write failure는 여전히 non-result이며, 후속 run 결과는
campaign ledger에서 각각 구분합니다.

Native-Wi-Fi/isolated-Debian 서버 architecture는 일시 중지돼 있습니다. 복구 종결
이후 그 통합 steady state가 product 목표입니다. 정확한 continuation 상태는 현재
GOAL과 target contract를 따르며, 이 페이지는 candidate나 recovery를 활성화하지 않습니다.

## 주요 milestone

1. Native static `/init`가 ACM control을 갖춘 stable resident PID 1과
   recovery-safe boot-only iteration에 도달했습니다.
2. USB가 ACM에서 composite NCM과 bounded TCP control로 확장됐습니다.
3. Native internal WLAN이 association, DHCP, IP traffic에 도달했습니다.
4. Native audio가 calibrated internal-speaker PCM playback과 cleanup에
   도달했습니다.
5. 특정 bounded handoff run에서 Debian PID 1, SSH, DRM/display ownership,
   return, cleanup을 증명했습니다.
6. Direct read-only UFS handoff가 이전 SD work-copy dependency를 제거했습니다.
7. Self-built-kernel track이 exact compiler를 확보하고 public-MPGen
   locator/RTIC structural defect를 닫았습니다. 반복 가능한 정상 운영은 열려 있습니다.
8. 후속 demo candidate에서 runtime·관측 실패가 드러났으며, H41 playback과
   rollback/health 종결은 이전 결과와 구분합니다.

## Architecture 요약

```text
bootloader
  -> Samsung 4.14.190 vendor kernel
    -> native static /init (host PID 1, hardware/recovery supervisor)
      -> ACM + NCM control/observation
      -> native-owned Wi-Fi and required vendor hardware bring-up
      -> isolated child namespaces
        -> read-only UFS Debian root
        -> Debian PID 1 + minimal /dev + authenticated SSH
```

마지막 두 Debian line은 선택된 architecture를 나타냅니다. 이전 run은 중요한
구성요소를 증명했지만, 하나의 run에서 이 steady state 전체를 증명하지 않았습니다.
