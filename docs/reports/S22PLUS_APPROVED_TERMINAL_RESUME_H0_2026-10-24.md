# S22+ approved terminal continuation — H0, 2026-10-24

## Problem and bounded result

P456 started through the approved terminal connector and proved automatic
Debian initial PID1 through installed services and same-boot SSH. The connector
exposed only initial launch, status and logs, so the physical-return pause
still required the operator to enter a host CLI command. A later transient ADB
read failure also required an original-owner health continuation. P456 is now
`ANDROID_CLOSED_HEALTHY`; its one N transfer, one A transfer and retained evidence
are closed. This H0 change fills the two missing transport operations for
future separately authorized automatic-boot tasks. It does not replay P456.

`continue_approved_task` resumes only the existing automatic-boot ready state,
within the original grant and return window, after physical Download. It binds
the existing approval, finished initial dispatch, consumed operation, F1 owner,
raw-validated pre-return steps, shutdown and return request before starting the
fixed original `continue --attended` CLI.

`resume_approved_health` requires one existing `install-android` intent and the
original adapter's raw-derived completed A transfer. Its fixed original
`recover --attended` command follows the existing-A branch, which cannot dispatch
another image. The same host epoch, owner, task and current sources remain
required. This path does not renew an expired grant or authorize a new native
operation. Uncertain A evidence rejects before process creation.

Both operations publish exclusive durable intents before launch, retain
separate process/result/log records, and return existing state on duplicate or
uncertain requests. They take the existing target lease during admission;
the original CLI owns that lease during execution and checks its journal again.
A racing manual command cannot replay an already-intended transfer. A prior
continuation must have a bound process exit before health continuation.
No user-supplied shell, executable, approval, operation or arbitrary path is
accepted. Attendance and physical Download requirements remain unchanged.
