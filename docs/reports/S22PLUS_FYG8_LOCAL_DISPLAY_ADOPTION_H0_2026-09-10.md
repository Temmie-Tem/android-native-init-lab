The local HUD starts before OPEN/AUTH under `local-display-v1`. The new observer
validates authenticated bootstrap and cached before-auth stage61/62 semantics,
then executes the fixed native health command and fresh idle STATUS. At most one
fixed optional HUD command follows. If its full budget cannot fit, it is skipped.

nonce, kernel boot identity, both boot semantic fields, endpoint, lane and source.
It writes and reopens that intent before sending CONTROL. The existing 30-second
return window is not renewed. Operator-plan commands are not admitted.

HUD acquisition/validity/metrics and reported DRM flips are observations separate
from fixed native health. Pixel output remains UNPROVED. Authentication, framing
or transport failures stop further commands. A saved intent remains consumed
even if an error occurs before CONTROL's first byte. The original raw stream and
retained TX are reauthenticated when the common evidence reader reopens results.
