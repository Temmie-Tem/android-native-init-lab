# S22+ FYG1 CP의 n78 송신 경로와 I/Q 버퍼

국내 SKC `SM-S906N / g0q`의 FYG8 배포본에 들어 있는 모뎀은
`S906NKSS7FYG1`이다. 이 CP의 공장 시험 모드(FTM)에는 n78 경로를 준비하고
샘플 버퍼를 Sub-6 송신 제어부에 전달하는 코드가 있다. **순정 벡터 공급 함수는
0을 반환하므로 조사한 경로에서는 샘플 복사가 시작되지 않는다.** 아래의 복사와
소비 경로는 공급자가 유효한 포인터와 길이를 반환한다는 가정 아래 추적했다.
FYG1 코드에 대한 결과는 호스트에 보관한 순정 파일의 정적 분석(H0)에서 얻었다.

## 지정한 I/Q 샘플과 n78 송신 측정의 대조

**모뎀 코드가 지정한 I/Q 샘플열이 그대로 n78 RF 출력에 반영됐는지는 미확인이다.** 보관된 FYG1 CP 아카이브의 SHA-256을 아래 기준값과 다시 대조했다. 기존 H0 기록(`sample-return-h0.9ij7zs43/result.json`)에서 조사한 순정 함수는 유효한 입력 레코드에서도 반환값과 출력 샘플 길이가 모두 0이며, 호출자는 복사 전에 종료한다. 따라서 이 경로에서 실제 송신에 쓰였다고 식별할 입력 샘플열이 없다. 이 결과의 범위는 해당 순정 함수와 호출자까지다.

삼성은 국내 `SM-S906N`의 n78 지원을 명시한다. 아래 두 비교 기기는 제조사 사양이 Snapdragon 8 Gen 1(SM8450)으로 확인되며, 프랑스 전파관리청(ANFR)이 공개한 시험성적서에는 n78 송신 조건과 전자파흡수율(SAR) 실측이 함께 있다. ### 독립 수신기의 n78 상향링크 I/Q 기록

**SM8450 단말이 참여한 n78 무선 신호를 독립 수신기로 기록한 공개 사례가 있다.** Luo 등의 USENIX Security 2025 논문 표 1은 시험 단말을 Galaxy S22 기본형 `SM-S901E/DS`, 모뎀을 Snapdragon X65로 식별한다. 삼성의 기종표에서 S22의 E형 칩셋은 Snapdragon 8 Gen 1(SM8450)이다. 연구진은 20 MHz n78 TDD 시험망에서 기지국과 별도의 USRP 수신기로 상향링크를 관측했다. 네 단말이 동시에 접속한 시험에서는 수신 I/Q를 파일에 저장했다. 이 기록에는 다른 단말의 신호도 포함될 수 있다. [삼성 기종표 10쪽](https://www.commoncriteriaportal.org/nfs/ccpfiles/files/epfiles/st_vid11444-st.pdf#page=10) · [논문의 시험 구성·표 1, PDF 9쪽](https://www.usenix.org/system/files/usenixsecurity25-luo-shijie.pdf#page=9) · [상향링크 I/Q 수집, PDF 10쪽](https://www.usenix.org/system/files/usenixsecurity25-luo-shijie.pdf#page=10)

공개 자료 v1의 ZIP 파일 목록을 확인했다. 삼성 단말 연결 예제에는 수신 I/Q 파일 `example.fc32` 1개, 로그 2개, 패킷 캡처 1개가 있고, 별도 평가 결과 ZIP에는 `.fc32` 파일 10개가 있다. 논문이 기지국 기록과 대조한 대상은 복호한 메시지다. 공개 파일 목록과 저자의 설명에서는 **같은 송신 시점에 단말 모뎀이 입력으로 사용한 I/Q 샘플열**을 식별할 수 없었다. [공개 수신 예제 파일 목록](https://zenodo.org/records/15601773/preview/example-connection-samsung-srsran.zip?include_deleted=0) · [저자의 평가 자료 목록](https://zenodo.org/records/15601773/preview/sni5gect-evaluation-results.zip?include_deleted=0)

**FYG1 적용 범위.** 수신 I/Q에는 전파 경로와 수신기의 영향도 담긴다. 이 자료는 n78 상향링크 파형을 외부에서 관측했다는 근거다. 같은 송신의 모뎀 입력 샘플이 없어 샘플별 진폭·위상 일치는 판정할 수 없다. 시험 단말도 `SM-S901E/DS`이므로 국내 S22+ `SM-S906N`의 FYG1 실행 결과로 옮길 수 없다.

### 삼성 연결 예제의 상향링크 DMRS 실측 대조

**기지국 로그의 상향링크 공유 채널(PUSCH) 할당 78건을 모두 수신 I/Q에서 대조했다. 데이터 CRC가 통과한 77건 모두에서 표준으로 재구성한 복조 기준 신호(DMRS)가 관측됐다.** CRC 실패 1건에서는 같은 일치를 확인할 수 없었다. 삼성 연결 예제 v1 ZIP의 배포자 MD5와 내부 파일 CRC를 확인했다. `example.fc32`는 복소 샘플 471,628,800개로, 23.04 MS/s에서 20.47초다. 같은 ZIP의 `gnb.log`에서 한 연결의 할당을 시간순으로 읽었다. [공개 예제 파일 목록](https://zenodo.org/records/15601773/preview/example-connection-samsung-srsran.zip?include_deleted=0)

로그의 n78 셀은 PCI 1, 부반송파 간격 30 kHz, 자원 블록 51개를 사용했다. 수신 파일에서 10 ms 주기의 1차 동기 신호(PSS)로 프레임 경계를 찾았다. 로그에서 유일하게 24개 자원 블록을 할당한 프레임 171의 슬롯 7을 데이터 심볼의 대역별 전력으로 식별했다. 해당 대역과 비교 대역의 전력비는 30.61 dB였고, 다른 프레임의 최댓값은 11.89 dB였다. 이 기준점과 로그의 프레임·슬롯 간격으로 78건의 위치를 정했다. FFT 창의 위치는 각 할당의 순환 접두부로 정했다.

로그의 자원 블록 범위, DMRS 형식 1, 단일 포트 0, 스크램블링 ID 1, `n_SCID=0`으로 슬롯의 심볼 2·7·11에 해당하는 기준열을 재구성했다. 심볼 2의 수신 파일럿으로 부반송파별 복소 채널을 추정하고, 그 채널과 기준열로 심볼 7·11의 수신값을 각각 예측했다. 아래 수치는 예측 벡터와 실제 수신 벡터의 **복소 내적 절댓값을 두 벡터의 노름 곱으로 나눈 상관**이다. 값 1은 두 벡터가 하나의 공통 복소 배율까지 일치한다는 뜻이다. [3GPP TS 38.211 §6.4.1.1의 기준열 생성](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/16.10.00_60/ts_138211v161000p.pdf#page=72) · [자원 요소 매핑](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/16.10.00_60/ts_138211v161000p.pdf#page=75)

| 기지국 데이터 CRC | 할당 수 | 세 심볼의 파일럿 자원 요소 수 | 로그 ID로 예측한 상관 | ID만 2로 바꾼 대조군 |
| --- | ---: | ---: | --- | --- |
| 통과 | 77 | 9,324 | 154회 비교에서 0.99935–0.99985, 중앙값 0.99976 | 0.05134–0.37923, 중앙값 0.14401 |
| 실패 | 1 | 108 | 0.11122, 0.24381 | 0.10125, 0.13932 |

추가로 심볼 2의 파일럿을 하나씩 건너뛰며 채널을 추정하고, 추정에 쓰지 않은 안쪽 주파수의 채널을 양옆 값으로 선형 보간했다. CRC 통과 77건에서 이 주파수들로 세 심볼을 검산한 상관의 최솟값은 0.99947이었다. 실패 건은 프레임 353의 슬롯 7이었으며 기지국도 SINR −23.2 dB를 기록했다. 이 자료로 해당 건의 실패 원인까지 특정할 수는 없다.

이 파일럿 비교로 표준 DMRS의 주파수·심볼 위치와 상대 복소 패턴을 확인했다. 할당별 결과와 입력·분석 코드 해시는 `workspace/private/analysis/s22plus-public-rx-dmrs.rUwTvLV1/`의 `verified.json`과 `inputs.sha256`에 보관했다.

### 같은 녹음의 PUSCH 데이터 심볼과 시간영역 I/Q

**CRC를 통과한 77건의 전송 블록으로 데이터 구간의 변조 심볼 68,376개를 재구성했다. DMRS로만 채널을 추정해 수신 I/Q를 등화한 뒤 가장 가까운 QPSK·64QAM 성상점을 판정했을 때, 재구성값과 다른 심볼은 0개였다.** 개별 수신점과 이상적인 성상점 사이에는 오차가 남았다.

같은 ZIP의 `gnb_mac.pcap`에는 잘리지 않은 상향링크 MAC 전송 블록 77개(45,047바이트)가 있었다. PCAP의 단말 임시 식별자, HARQ 프로세스, 프레임·서브프레임, 블록 길이와 기록 시각을 `gnb.log`의 PHY 결과와 대조해 77개 모두 일대일로 연결했다. 두 기록의 시각 차이는 최대 0.252 ms 이내였다. 앞 절에서 확인한 각 할당의 FFT 창을 그대로 사용했다. [공개 시험 자료](https://zenodo.org/records/15601773/preview/example-connection-samsung-srsran.zip?include_deleted=0)

로그의 변조·부호화 조건에 맞춰 전송 블록 CRC, 코드 블록 분할, LDPC 부호화, 레이트 매칭, 스크램블링과 변조를 순서대로 적용했다. 모든 LDPC 코드워드의 패리티를 검사했다. 64QAM 두 건은 1비트 HARQ-ACK도 전송했다. 아래 집계에는 ACK가 배치된 6개 자원 요소와 UL-SCH 데이터가 배치된 68,370개가 들어 있다. [TS 38.212의 UL-SCH 부호화·다중화](https://www.etsi.org/deliver/etsi_ts/138200_138299/138212/16.14.00_60/ts_138212v161400p.pdf#page=35) · [TS 38.211의 PUSCH 스크램블링·변조](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/16.10.00_60/ts_138211v161000p.pdf#page=33)

채널 추정에는 각 할당의 DMRS 심볼 2·7·11만 사용했다. 로그의 반송파 주파수에 따른 OFDM 심볼 위상과 DMRS 전력비를 반영하고, 파일럿에서 측정한 채널의 크기와 위상을 주파수·시간 방향으로 선형 보간했다. 바깥쪽 자원 요소에는 같은 기울기로 외삽했다. 데이터 구간의 이득·위상을 수신 데이터에 맞춰 추가 조정하지 않았다. 표의 EVM은 등화 후 오차 에너지 합을 이상적인 변조 심볼 에너지 합으로 나눈 값의 제곱근이다. [TS 38.211 §5.4](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/16.10.00_60/ts_138211v161000p.pdf#page=31) · [TS 38.214 표 6.2.2-1](https://www.etsi.org/deliver/etsi_ts/138200_138299/138214/16.16.00_60/ts_138214v161600p.pdf#page=149)

| 변조 | 할당 수 | 비교한 심볼 | 성상점 판정 불일치 | 전체 심볼의 RMS EVM |
| --- | ---: | ---: | ---: | ---: |
| QPSK | 2 | 3,564 | 0 | 4.11% |
| 64QAM | 75 | 64,812 | 0 | 2.78% |
| 합계 | 77 | 68,376 | 0 | 2.86% |

할당된 부반송파에서 **채널을 적용한 예측값과 수신 FFT 값의 정규화 상관은 할당별 0.99909–0.99972, 중앙값 0.99965**였다. 데이터 스크램블링 ID만 바꾸고 채널과 전송 블록을 유지한 대조군의 상관은 0.03316–0.12216이었다.

**시간영역에서도 같은 데이터 구간을 대조했다.** 각 할당의 예측값을 해당 부반송파에 놓고 나머지를 0으로 두어 역 FFT했다. 순환 접두부를 제외한 847개 창(각 768샘플)을 `example.fc32`의 필터링 전 복소 샘플 650,496개와 직접 비교했다. 할당별 상관은 0.99824–0.99918, 중앙값 0.99899였다. 전체 RMS 잔차는 예측 신호 RMS 대비 **4.60%**였다. 같은 기준으로 할당된 부반송파 안에서만 계산한 잔차는 **2.79%**였다. 시간영역 잔차에는 할당 바깥에서 수신된 에너지도 들어가며, 두 성분의 에너지 합을 파르세발 등식으로 검산했다.

이 결과는 **이 삼성 연결 예제에서 기지국이 복호한 블록으로 독립 수신기의 표준 상향링크 데이터 구간을 어느 정도 예측할 수 있는지** 보여 준다. 단말의 DAC 입력 샘플과 절대 송신 진폭·위상은 기록돼 있지 않다. 국내판 `SM-S906N`에서 FYG1이 임의 I/Q를 재생할 수 있는지는 미확인이다. 할당별 측정값과 계산 코드·입력의 해시는 위 비공개 분석 폴더의 `pusch-data/verified-data.json`과 `pusch-data/analysis.sha256`에 보관했다.

### 순환 접두부를 포함한 PUSCH 슬롯 전체의 수신 I/Q

**CRC 통과 77건에서 슬롯마다 0.5 ms를 연속으로 대조했다. 총 887,040개 복소 샘플에서 슬롯별 정규화 상관은 0.99739–0.99872(중앙값 0.99800), 전체 RMS 잔차는 6.28%였다.** 잔차는 `example.fc32`의 필터링 전 수신값과 예측값 간 차이의 RMS를 예측값의 RMS로 나눠 계산했다. 슬롯 전체에 추가 이득이나 위상 보정은 적용하지 않았다. [공개 삼성 연결 예제](https://zenodo.org/records/15601773/preview/example-connection-samsung-srsran.zip?include_deleted=0)

앞 절의 할당과 타이밍을 사용해 데이터 심볼 11개와 DMRS 심볼 3개를 송신 순서로 배치했다. 할당 밖의 부반송파는 0으로 두고, 각 심볼의 채널을 적용한 뒤 역 FFT했다. 23.04 MS/s에서 유효 심볼은 768샘플이며, 순환 접두부(CP)는 첫 심볼에서 66샘플, 나머지 13개 심볼에서 각각 54샘플이다. 앞 절의 FFT 창은 추정한 유효 구간 시작보다 27샘플 앞서므로, 그 차이를 되돌리고 각 심볼 꼬리를 접두부로 붙였다. 이로써 슬롯당 11,520샘플을 빈틈이나 중복 없이 비교했다. [TS 38.211 §5.3.1의 심볼·접두부 길이](https://www.etsi.org/deliver/etsi_ts/138200_138299/138211/16.10.00_60/ts_138211v161000p.pdf#page=27)

| 비교 구간 | 복소 샘플 수 | 슬롯별 상관 중앙값 | 전체 RMS 잔차 |
| --- | ---: | ---: | ---: |
| 데이터 심볼의 유효 구간 | 650,496 | 0.99844 | 5.57% |
| DMRS 심볼의 유효 구간 | 177,408 | 0.99883 | 4.80% |
| 14개 심볼의 접두부 | 59,136 | 0.99134 | 13.76% |
| 슬롯 전체 | 887,040 | 0.99800 | 6.28% |

데이터 유효 구간의 5.57%는 심볼 경계에 맞춘 값이다. 앞 절과 같은 27샘플 이른 창을 꺼내면 기존의 4.60%가 재현된다. 접두부의 예측 대비 잔차는 앞 절반 **18.53%**, 뒤 절반 **4.75%**였다. 녹음에서 접두부와 768샘플 뒤의 실제 심볼 꼬리를 직접 대조해도 두 구간의 차이는 꼬리 RMS 대비 18.93%였다. 슬롯 경계는 기존 수신 접두부 상관으로 추정했으며, 이 기록에서 경계 오차와 송수신 필터·전파 경로가 각각 얼마나 기여했는지는 분리할 수 없다.

표의 DMRS 행에서는 해당 파일럿을 채널 추정에도 사용했다. 이를 검산하기 위해 DMRS 심볼을 하나씩 제외하고 다른 두 DMRS로 그 심볼과 접두부를 예측했다. 데이터 심볼에는 앞 절의 세 DMRS 채널 추정값을 사용했다. 이때 **DMRS 유효 구간 잔차는 6.00%, 슬롯 전체 잔차는 6.49%, 슬롯 전체 상관 중앙값은 0.99783**이었다. 확인한 범위는 이 공개 시험의 수신 슬롯 파형까지다. 단말의 송신 전 I/Q와 국내판 FYG1의 임의 파형 재생 능력은 이 기록에서 판정할 수 없다. 슬롯별 결과와 입력·분석 코드 해시는 위 비공개 분석 폴더의 `pusch-data/slot-comparison/verified-slots.json`, `prefix-check.json`, `analysis.sha256`에 보관했다.

### 정수 샘플 경계 보정으로 설명되는 접두부 앞 절반의 오차

**원래 측정한 접두부 앞 절반 29,568샘플에서, 슬롯 경계를 정수 샘플 단위로 옮겨 설명할 수 있는 양은 잔차 에너지의 최대 0.22%였다.** 이 상한은 앞 절에서 추정한 채널과 각 심볼의 위상을 고정하고, 한 슬롯의 14개 심볼 경계를 같은 양만큼 옮기는 모델에 적용된다. 77건에 공통으로 적용할 최적 보정은 **0샘플**이었다.

기존 경계에서 −54부터 +54샘플까지 1샘플(43.40 ns)씩 검사했다. 양수는 경계를 늦춘다는 뜻이다. 각 슬롯 안의 13개 전환점에서 앞 54샘플과 뒤 54샘플을 고정하고, 어느 샘플부터 다음 심볼의 파형이 수신값을 더 잘 설명하는지 제곱오차 합으로 판정했다. 보정 효과는 원래의 접두부 앞 절반에서 평가했다. 아래 RMS의 분모도 원래 예측 신호의 RMS로 고정했다.

| 경계 보정 방법 | 같은 29,568샘플의 RMS 잔차 | 원래 잔차 에너지 대비 변화 |
| --- | ---: | ---: |
| 77건 공통 보정 | 18.533% | 변화 없음 |
| 슬롯마다 13개 전환점으로 보정 | 18.523% | 0.112% 감소 |
| 같은 슬롯의 홀수 전환점으로 정해 짝수에서 검산하고, 반대로도 검산 | 18.552% | 0.207% 증가 |

슬롯별 보정은 **73건에서 0샘플, 4건에서 +1샘플**이었다. 표에는 슬롯 내부 전환점의 27,027샘플에 보정을 적용했다. 슬롯 첫 접두부의 2,541샘플은 직전 슬롯 파형이 없어 기존 오차를 포함했다. 이 제약의 영향도 계산했다. 각 후보에서 직전 슬롯 몫으로 바뀌는 첫 접두부 샘플의 오차를 모두 0으로 허용하고, 슬롯마다 평가 샘플에 가장 유리한 보정을 골라도 RMS 잔차 하한은 **18.513%**였다. 원래 18.533%에서 최대 **0.020%p**, 잔차 에너지로는 **0.218%** 줄어드는 셈이다.

평가할 구간 자체를 8샘플 늦추면 RMS는 **4.82%**까지 낮아졌다. 이 계산에서는 원래 오차가 컸던 첫 8샘플이 평가에서 빠진다. 반면 예측 파형 전체를 녹음에 대해 통째로 앞뒤로 옮겨도 최솟값은 0샘플이었다. 따라서 오차가 경계 부근에 집중된 현상은 확인되지만, 원래 샘플의 오차가 일관된 정수 샘플 위치 보정으로 줄어드는 효과는 교차검증에서 관측되지 않았다. 분수 샘플 지연과 필터 응답의 개별 기여도는 미확인이다. 109개 보정값의 곡선, 슬롯별 결과와 계산 코드 해시는 위 분석 폴더의 `pusch-data/slot-comparison/boundary-sweep/results.json`과 같은 디렉터리의 `analysis.sha256`에 보관했다.

### 분수 샘플 경계 보정의 다른 심볼 교차검증

**같은 77건의 원래 접두부 앞 절반 29,568샘플에서 RMS 잔차가 18.533%에서 16.784%로 줄었다.** 각 슬롯의 다른 심볼에서 접두부 앞 절반 오차가 최소인 보정값을 정한 결과다. 감소량은 **1.749%p**, 원래 잔차 에너지 대비 **17.98%**였고, 두 검증 방향을 합치면 77건 모두에서 오차가 줄었다.

기존 수신 샘플의 위치, 채널 추정값, RMS 분모를 고정했다. 직전 정수 실험에서 선택된 보정값 주변을 포함하도록 −2에서 +2샘플까지 1/64샘플(약 0.68 ns) 간격으로 검사했다. 각 OFDM 심볼 내부의 위상을 수신기 시간축에 고정한 채 심볼 전환 시점만 옮겼다. 정수 사이의 전환은 65탭 Kaiser 창을 쓴 sinc 분수 지연 필터로 계산했다. 보정값이 0일 때 77건 각각의 원래 오차가 재현됐고, 합성 신호에 넣은 −0.625와 +0.3125샘플 지연도 각각 회수됐다. [분수 지연 필터 설계](https://research.aalto.fi/en/publications/splitting-the-unit-delay-tools-for-fractional-delay-filter-design/)

심볼 번호 0–13 중 홀수 7개의 접두부에서 보정값을 골라 짝수 심볼을 평가하고, 짝수 6개(2–12)로 골라 홀수 심볼을 평가했다. 첫 심볼은 평가에만 썼다. 두 방향의 제곱오차를 합쳐 각 원본 샘플을 한 번씩 집계했다.

| 보정값을 정한 방법 | 검증 심볼의 접두부 앞 절반 RMS | 잔차 에너지 감소율 |
| --- | ---: | ---: |
| 슬롯별, 다른 심볼의 접두부 앞 절반 | 16.784% | 17.98% |
| 77건 공통, 다른 심볼의 접두부 앞 절반 | 16.790% | 17.93% |
| 슬롯별, 직전 정수 실험과 같은 경계 양쪽 108샘플 | 18.104% | 4.58% |

77건 공통 보정값은 홀수 심볼에서 **+0.296875샘플**, 짝수 심볼에서 **+0.3125샘플**이었다. 양수는 전환을 늦추는 방향이다. 슬롯별 주 분석에서 보간 필터를 129탭으로 늘리면 검증 RMS는 **16.860%**였다. 첫 심볼의 시작 전에는 해당 PUSCH 할당의 기여를 0으로 두었다. 직전 슬롯 파형이 미확인인 첫 심볼의 2,541샘플을 보정 전 오차로 집계해도 전체 RMS는 **16.848%**였다.

**오차 감소는 주로 경계 뒤쪽에 집중됐다.** 접두부 앞 절반으로 정한 슬롯별 보정을 같은 검증 전환점에 적용하면, 내부 경계 직전 54샘플의 잔차 에너지는 **17.12% 증가**했다. 경계 앞뒤 54샘플씩 합친 108샘플에서는 **1.23% 감소**했다. 파형 전체를 통째로 지연시키는 대조 계산의 접두부 앞 절반 RMS는 **18.619%**였다. 약 0.3샘플은 이 보간 모델에서 접두부 앞부분을 잘 예측하는 값이다. 이 녹음만으로 실제 슬롯 시계 오차와 송수신 필터 응답을 분리할 수 없다. 슬롯별 보정값, 검증 오차, 입력·분석 코드 해시는 위 분석 폴더의 `pusch-data/slot-comparison/fractional-boundary/results.json`과 같은 디렉터리의 `analysis.sha256`에 보관했다.

### 공통 FIR을 적용했을 때 경계 양쪽의 수신 잔차

**다른 심볼에서 추정한 7탭 공통 FIR을 약 0.3샘플 지연 예측에 적용하자, 경계 직전 54샘플과 접두부 앞 27샘플의 RMS 잔차가 함께 줄었다.** 지연만 적용했을 때와 비교하면 각각 **14.02% → 11.13%**, **17.00% → 13.42%**였다. 두 검증 방향 모두에서 감소했고, 슬롯별로도 77건 중 76건에서 두 구간이 동시에 개선됐다.

슬롯마다 앞 심볼과 뒤 심볼이 모두 알려진 내부 경계 13곳에서 `example.fc32`의 같은 108샘플(−54…+53)을 사용했다. 총 1,001개 경계, 108,108샘플이다. 표의 RMS는 각 구간의 잔차 에너지 합을 같은 구간의 무보정 예측 에너지 합으로 나눈 값의 제곱근이다. 각 열의 분모와 수신 샘플은 모든 모델에서 동일하다. [공개 삼성 연결 예제](https://zenodo.org/records/15601773/preview/example-connection-samsung-srsran.zip?include_deleted=0)

| 수신 파형 예측 | 경계 직전 54샘플 | 접두부 앞 27샘플 | 경계 앞뒤 108샘플 |
| --- | ---: | ---: | ---: |
| 무보정 | 12.95% | 18.79% | 13.47% |
| 약 0.3샘플 지연 | 14.02% | 17.00% | 13.39% |
| 7탭 공통 FIR만 적용 | 10.46% | 14.36% | 10.86% |
| 같은 지연과 7탭 공통 FIR | **11.13%** | **13.42%** | **10.88%** |

홀수 경계에서 학습해 짝수에서 검증하고 반대 방향도 검사했다. 각 방향에서 지연은 앞 절의 공통값(+0.296875 또는 +0.3125샘플)으로 고정했다. FIR은 지연 예측 주변 ±3샘플에 대한 복소 계수 7개를 학습 경계 양쪽 108샘플의 최소제곱으로 한 번 추정해, 그 방향의 77건과 경계 양쪽에 공통으로 적용했다. 지연만 쓴 경우 대비 잔차 에너지 감소율은 경계 직전 **36.98%**, 접두부 앞 절반 **37.69%**, 108샘플 전체 **34.00%**였다. 예외는 가장 넓은 24개 자원 블록을 사용한 프레임 171의 슬롯 7로, 두 구간 모두 잔차가 증가했다. 직전 슬롯 파형이 미확인인 첫 경계는 표에서 제외했다. 앞 절과 같이 첫 경계의 접두부도 포함한 원래 29,568샘플에서는 **16.79% → 13.29%**였다.

더 엄격한 검산에서는 지연을 +0.300샘플로 고정하고, 검증 경계와 양옆 경계를 전부 FIR 학습에서 제외해 검증 심볼 쌍이 학습에 들어가지 않도록 했다. 채널 추정에도 경계에서 떨어진 DMRS 샘플만 쓰도록, 짝수 부반송파 파일럿의 반 심볼 반복성을 이용해 경계 창과 겹치는 입력을 대체했다. 이 검산에서도 지연 단독 대비 지연과 FIR의 RMS는 직전 **14.02% → 11.14%**, 접두부 앞 절반 **16.98% → 13.42%**, 108샘플 전체 **13.40% → 10.90%**였다.

공통 FIR은 이 녹음에서 DMRS 채널 추정 후에도 남는 송수신 경로의 결합 응답을 근사한다. 송신기와 수신기의 물리적 필터를 개별적으로 식별할 수는 없다. FIR만으로도 108샘플 전체 잔차가 비슷한 점은 약 0.3샘플의 물리 지연을 이 비교만으로 특정하기 어렵다는 근거다. 검증 방향·슬롯별 오차와 계산 코드 해시는 위 분석 폴더의 `pusch-data/slot-comparison/common-fir/results.json`과 같은 디렉터리의 `analysis.sha256`에 보관했다.

| 대역 조회 | 72바이트 대역 테이블에서 내부 값 `0x20`, `0x21`, `0x22`는 각각 n77, n78, n79에 대응한다. 국내 HWID 11·12·15의 RFC 설정 모듈 모두 96바이트 보드 행에서 모드 19와 대역 바이트 `0x21`이 일치한다. 그 행의 TX 경로 수는 4이며 포인터는 416바이트 `nr5g_band78_tx_path_info` 객체를 가리킨다. |
| 준비와 할당 | PREP은 carrier의 대역 행을 확인하고 장치·신호·안테나 경로로 FTM 경로 항목을 선택한다. 여기에 논리 경로와 carrier 비트를 기록하고 해당 항목의 TX 슬롯에 핸들을 할당하거나 기존 핸들을 재사용한다. |
| 활성화와 열거 | 확인한 실행 후 처리 분기는 준비된 할당 마스크를 활성 마스크로 복사한다. `TX_CONTROL`은 활성 항목에서 현재 TX 슬롯(0 또는 1)의 유효 비트와 핸들 값을 검사한다. 유효하고 값이 −1이 아닌 핸들이 송신 요청의 배열에 들어간다. |
| 하위 소비 | `rfe_nr5g_toggle_sdriu_tx`는 요청의 핸들, 버스 주소와 워드 수를 읽는다. 핸들이 SDR735v2 구현을 선택하고 워드 수가 양수이면 그 메서드는 장치·체인별 제어 위치 두 곳에 주소와 워드 수를 기록한다. |

송신 시 열거 함수는 대역을 다시 검사하지 않는다. 특정 핸들을 n78에 귀속하려면
같은 carrier의 준비 경로 인덱스와 송신 시점의 활성 슬롯이 이어져야 한다.
보드의 네 TX 후보 중 어느 항목이 특정 PREP 입력을 공급했는지, 그 핸들이 선택한
하드웨어가 실제로 n78 튜닝을 완료했는지는 미확인이다.

## 복사 후 4 KiB 채움과의 겹침

LL1 설정 응답 `NR5G_LL1_CAL_FTM_CFG_CNF`의 생성 코드는 CPU 주소
`0x2A664B80`, MNOC 값 `0x00C64B80`, 예약 크기 `0x30200`바이트를
각각 응답의 +36, +40, +44에 넣는다. 수신 핸들러가 이를 FTM 문맥으로 옮긴다.
로더는 길이 `L`에서 완전한 32비트 워드만 복사한다. 송신 요청에는 원래 바이트
길이와 7비트 우측 시프트한 MNOC 값이 들어가고 하위 송신 서술자의 길이는
`⌊L/4⌋`워드가 된다.

| 정상 초기화 경로 | CPU 주소 범위 (끝 주소 제외) | 크기 |
| --- | --- | ---: |
| LL1이 보고한 I/Q 예약 영역 | `[0x2A664B80, 0x2A694D80)` | 197,120바이트 |
| 복사 후 고정 패턴을 쓰는 영역 | `[0x2B69A000, 0x2B69B000)` | 4,096바이트 |

PSAMP 풀의 초기 할당값 `0x2B694800`에서 조회 콜백의 보정 `+0x2400`,
LMEM 초기화의 `+0x3000`, 채움 루프의 `+0x400`을 따라가면 두 번째 구간의
시작 주소가 나온다. 두 구간 사이에는 `0x1005280`바이트가 있어 기본 로더가
예약 영역 안에 복사한 샘플은 이 루프에서 덮이지 않는다. 추적한 복사 루프에는
입력 길이를 예약 크기와 대조하는 검사가 보이지 않았다.

PSAMP 조회 실패 후 파일상 대체 상수를 적용하면 채움 범위는
`[0x600, 0x1600)`, 보정된 복사 시작 주소는 `0x52664B80`이다. 수치상
두 구간은 떨어져 있다. 저주소 쓰기의 유효성, 보정 주소와 MNOC 대상의 대응,
대체 분기의 정상 완료는 확인되지 않았다. 다른 할당이나 앞선 실패 이력이
있을 때에는 실제 CPU 주소로 비교해야 한다. 복사 시작을 `X`, 실제 복사 길이를
`N = 4⌊L/4⌋`, 채움 기준을 `B`라고 하면 같은 주소 공간의 비순환 구간에서
`N > 0`, `X < B + 0x1400`, `B + 0x400 < X + N`을 모두 만족할 때 겹친다.

## 남은 질문

시험 송신 코드는 송신 지속 시간과 시작 심볼을 처리하고 슬롯 길이와 타이머로
목표 시각을 계산한다. 외부에서 지정한 샘플이 그 시각에 방사되는지를 판정하려면
I/Q의 비트 배치·부호·샘플률, 캐시 처리 후 하드웨어 읽기, 같은 핸들의 튜닝과
출력 시점이 더 필요하다. 이번 분석에는 RF 출력 측정이나 독립 수신기의
기지국 방송 채널(PBCH) 복호 결과가 없다.
