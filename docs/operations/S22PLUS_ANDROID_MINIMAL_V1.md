# S22+ minimal Android after the Android32 layout

Status: **REVIEW_GATED_FIXED_FOREGROUND_D0_D1**.

This separate profile serves the operator's explicit request to keep Android
as a minimal management/return environment after the 32 GiB G2 successor.
It requires its own source-bound independent PASS_GO, the same foreground
operator request and actual attendance for effects. It neither opens nor
renews a G2/F1 grant. The exact S22+ target adopts it only after review.

## Effects and final proof

D1 permits only one primary-user Package Manager uninstall for each selected
package, with fresh same-boot identity and unchanged package metadata before
its durable intent. Each command has its own intent, bounded raw response and
observed post-state. Uninstall is user-scoped: it may remove that unused app's
user data/cache and installation state through Package Manager. This is not a
promise that system APK bytes or a system partition become smaller. Reclaimed
space is measured from `/data` statfs, not inferred from disabled-app counts.

After successful selected removals, one ordinary Android reboot may be
intended. Fixed health, package state, full GPT and statfs must then prove a
different boot, the same 32 GiB userdata/native geometry, retained required
components, and numeric root with exact A/supporting digests. The final state
is Android. No Download, N/A transfer, GPT write, filesystem format or rootfs
staging is permitted by this lane.

A command or reboot with an intent never replays, including after a lost
response. An error stops further cleanup. The only automatic continuation is
one separately recorded close-only D0 reconciliation, bounded to 300 seconds,
which first prefers a complete retained result and otherwise reads current
health/state. It cannot uninstall, reinstall, reboot or renew research time.
A partial or uncertain cleanup remains explicitly incomplete even if Android
health is subsequently proved. Unavailable Android control requires operator
recovery under the binding contract; no hidden factory reset or F1 fallback is
created here. Complete retained raw results may be republished in H0.

The finite optional list and time/output bounds limit this foreground API
transaction. Review them when the declaration, package-state parser, required
component set, or effect/recovery graph changes. Goal closure/cancellation or
source/target drift ends the foreground scope. Earlier G2 journals, grants and
feature results remain unchanged.
