fresh exact rooted FYG8 Android health, installs N once, observes the resident
services across a thirty-minute interval, then returns through the existing

## Qualification and evidence

Fixed native-health checks establish the command/runtime boundary. Authenticated
bounded HUD exports separately establish retained matched-frame, source sequence,
freshness and CPU-sensor-coverage observations. Checkpoints must span at least
1,800,000 native BOOTTIME milliseconds and cross the old 601-sample/900-second
limits. Missing/failed sensors remain explicit; physical display, uninterrupted
operation between samples, thermal accuracy and kernel-stall recovery are not
inferred from checkpoint success. The retained diagnostic window is not a
lossless lifetime trace.

Only the existing exact CONTROL/Download/A return is used on the normal path.
Uncertain authentication, transport, command or terminal state stops observation;
no later checkpoint, candidate or CONTROL is replayed. Preauthorized exact A
recovery resumes only through the existing durable owner state and attended
physical fallback when required. No automatic DRM/module/USB reset is added.
