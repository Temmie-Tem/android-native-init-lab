## Finite ownership and return

One returned attended grant binds one fresh N, exact original A, target,
reviewed sources, qualified artifacts, pinned tools/SSH credentials, usable
physical Download recovery, one operation and 3600 original host BOOTTIME
seconds. No E, native baseline admission, prior tail, reentry, reconnect, HUD,
installation, repair, package workload or arbitrary command is included.

```text
healthy original A -> Download -> one N (owns all automatic startup)
  -> Debian initial shell PID1 / logger + prefix68 + UFS8
  -> complete protected root admission / first bounded file lifetime
  -> six remaining clients / checked sync, unmount and RO restoration
  -> settled children / checked RAM receipt / second complete protected admission
  -> one installed-root RW lifetime / RAM witness / installed SysVinit
  -> rcS / rc2 / first g1 NCM attempt / cron and sshd / 120-second local proof
  -> bounded same-boot pinned SSH evidence and health / one fixed shutdown
  -> attended physical Download / one original A / full Android32 health
```

The unique N transfer intent consumes all automatic preparation, both declared
native_data writable lifetimes, root transition, service startup, bounded
records and the one gadget attempt. There is no host REQUEST, CONTINUE, START
or RELEASE. Their absence is specific to this newly reviewed owner, not a
waiver of the predecessor's gates. Uncertain transfer/startup never replays.
The existing V3 owner, global candidate consumption and append-only journal
remain authoritative. A completed transfer or result may be reconstructed
from its original raw evidence; reconstruction performs no device action.

The device uses a single absolute 300000 ms CLOCK_BOOTTIME deadline, including
early preparation, both admissions, transition and 120-second observation.
No phase renews it. The host's read-only observation ends 360 seconds after
the original successful N transfer completion and before the grant deadline.
Before preflight and at the two existing N launch checks, reuse the file lane's
remaining-budget rule: more than 240 seconds for transfer, 360 for observation
and 600 for physical return must remain. This applies only before N; it never
blocks the original A recovery or renews a consumed budget.
USB observation has at most 180 samples, spaced by up to two seconds; fixed
SSH evidence and health have at most 180 and 30 reads within that same window.
Read failures retain bounded raw captures and may consume the next read only.
Malformed authenticated evidence stops the path. One separately journaled
fixed SSH shutdown is never retried after intent or uncertainty.

Normal return requests physical Download within at most 600 seconds and within
the original grant. Any failure retains the owner for the existing attended
original-A recovery. One A applies across normal and recovery paths. After
proved A, only remaining health/closure may continue. Full original boot/root,
changed boot, Android32/GPT health and durable closure are required. Original A
does not roll back native_data or establish that its filesystem is clean.
